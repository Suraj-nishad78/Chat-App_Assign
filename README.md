# React Chat App 💬

A responsive single-page chat application built with React.js that allows users to send messages, interact with messages using likes, and enjoy a clean, modern chat interface.

## ✨ Features

- **Send Messages:** Type and send messages using the input box or Enter key.
- **Random User Assignment:** Each message is assigned a random username from a predefined user list.
- **Like Messages:** Like or unlike messages with a dynamically updated count.
- **Responsive UI:** Clean chat interface optimized for desktop and mobile screens.
- **Auto-Scroll:** Automatically scrolls to the latest message.
- **Interactive Design:** Smooth animations, hover effects, and a user-friendly interface.

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- CSS3
- Vite

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
